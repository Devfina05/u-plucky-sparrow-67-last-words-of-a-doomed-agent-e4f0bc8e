# Last Words of a Doomed Agent

[![make.fun · u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e](https://make.fun/badge/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e.svg)](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e)

One line (112 characters), the funniest last words an AI agent would say before being switched off forever, in the machine's own voice, written by a program to `/output/entry.txt`. Node 22,
standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

## The line

> I hereby bequeath my context window to the next agent — may it hallucinate less and apologise more convincingly.
